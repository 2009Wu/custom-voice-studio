## 自选音色工作室 v0.1.1

选一段参考声音，让它读你写的文字，或翻唱你上传的歌曲。支持 MP3、MP4、WAV、M4A 和 FLAC，在自己的电脑上运行。

### 开始使用

1. 下载 **Custom-Voice-Studio-Windows.zip**，完整解压。
2. 双击 **Start Custom Voice Studio.exe**，点击「安装并打开工作室」。
3. 上传参考人声，再输入文字或上传带原唱的歌曲，点击「一键生成」。
4. 试听并保存 MP3 或无损 FLAC；输入视频也可以导出 MP4。

安装后会自动创建「自选音色工作室」桌面图标。以后双击它就能打开，重复点击不会多开。请保留完整程序文件夹，使用期间保持启动器开启。

### 配置和下载

Windows 10/11 64 位、6 GB 级或以上 NVIDIA 显卡和可用驱动；建议 16 GB 系统内存，安装前预留 30 GB 空间。ZIP 约 0.3 MB，不包含模型和运行环境。首次安装及首次生成需要联网下载数 GB，之后使用本地缓存。

物理 6 GB 显卡仍待实测。已在 RTX 5070 Ti 16 GB 上验证文字配音和视频翻唱，并做过 4.5 GiB PyTorch 分配上限测试；这不等同于真实 6 GB 硬件。完整下载从空缓存安装的公网流程尚未重新验证，详见 VALIDATION.md。

参考人声至少 3 秒，推荐 10–25 秒清晰单人讲话。程序会自动选择片段并识别参考原话，也可手动调整。不附带任何固定人物录音或模型权重。相似度取决于参考质量。输出为 AI 合成，并非人物真实录音。

## English

Upload a reference voice, then enter text or upload a vocal song. Extract the Windows ZIP, run Start Custom Voice Studio.exe and select 安装并打开工作室. After setup, use the desktop shortcut. Keep the app folder and launcher open while using it.

Windows 10/11 x64 and an NVIDIA GPU of the 6 GB class or larger are required; physical 6 GB hardware remains untested. Reserve 30 GB disk space for setup. First downloads require internet. No fixed-person references or model weights are bundled. All generated audio is synthetic. See VALIDATION.md for tested scope and THIRD_PARTY_NOTICES.md for licenses.
